# Fen Lisesi 9 — Öğrenme Platformu

Yayın: https://fenlisesi9.netlify.app · Veli/öğretmen paneli: /veli.html

- `index.html`, `veli.html`, `*-hNN.html`: yayınlanan site (Netlify `netlify.toml` yalnız HTML + robots.txt yayınlar)
- `kit_*`: paket üretim kiti (şablon, build yardımcısı, yol haritası, kalite listesi, örnek scriptler)
- `COWORK_GOREV.md`: haftalık üretim görevinin talimatı
- `apps-script-Code.gs`: arka uç (Google Apps Script) — değişince Apps Script'e yapıştır → Deploy → Manage deployments → New version
